4. (30.6–40.7) To find a value, save with one thousand gold, then with twelve fifty, and compare the two files. The bytes that changed are yours.
5. (40.7–48.9) Overwrite those four bytes with the biggest number they can hold. Save the file, load the game, and you are rich.
6. (48.9–61.4) Two traps. Never insert bytes, only overwrite, or everything after them shifts. And some games store a checksum, so an edited save looks corrupt.
7. (61.4–70.5) So back up the file first. And remember: a file is just memory that sits still.
