4. (29.3–42.4) A game on your disk is not C plus plus anymore. The compiler turned it into machine code: bytes that the processor runs. Assembly is those same bytes, written as text.

7. (69.9–85.9) First, the names. E A X, E C X, E D X. These are registers: small, very fast variables inside the processor itself. In thirty-two bit code, each one holds four bytes.
8. (85.9–98.7) Every line has the same shape: the instruction, then the destination, then the source. M O V, said move, copies the source into the destination.
9. (98.7–113.6) Square brackets mean memory, like last episode. E A X holds the address of the player. Four is the offset of health. So the line says: go to player plus four, and read the health into E C X.
10. (113.6–127.5) Now read all five. Get the player's address. Read the health. Subtract the damage. Get the address again. And write the result back into health. Read, change, write.

17. (227.1–244.7) Same question for the health: what reads it? Two instructions, hundreds of times each. Look at the first. Move E C X, brackets, E B X plus E C. E B X is the player. E C is the offset of health.
18. (244.7–263.8) Next line. C M P, E C X, one nine: compare the health with hex nineteen, twenty-five. Then J N G: jump if not greater. C M P sets flags, the jump reads them. That is what an if looks like in assembly.
19. (263.8–278.6) Our own program has the same pair: compare health with zero, then J G, jump if greater, right over the call to puts. The jump is the opposite of the if: the compiler skips the block when the condition is false.
20. (278.6–288.2) And the line from last time? Same parts, other direction. It writes E A X into the field at E B X plus E C.
21. (288.2–304.3) Second half: functions. Code needs scratch space in memory: the stack. Push puts a value on top. Pop takes the top value off. And one register, E S P, always holds the address of the top.
22. (304.3–320.1) Watch it in the game. I put a breakpoint just before two pushes, and fire. The game freezes on that line, and Cheat Engine shows every register. E S P is zero zero one A, F D three C.
23. (320.1–334.9) I let it run to the call. Two pushes later, E S P is zero zero one A, F D three four. Eight less. The stack grows downward: each push subtracts four from E S P.
24. (334.9–355.6) Now the call itself. One instruction later, we are inside the function. E S P dropped by four more, and on top of the stack sits zero zero four C, seven three F E: the line right after the call. The return address. Call pushes it. Ret pops it, and jumps back.
25. (355.6–366.4) And those pushes before the call? They are the function's arguments. In thirty-two bit code, arguments go on the stack, right above the return address.
26. (366.4–384.8) Our own program shows it cleanly. Add three, of one, two, three: push three, push two, push one, call. Last argument first. Then add E S P, twelve: the caller throws them away. That is C decl.
27. (384.8–398.6) Inside add three, the arguments are read at E B P plus eight, plus twelve, and plus sixteen. And the result is left in E A X: that is how a function returns a value.
28. (398.6–414.5) Methods get one twist. For P dot hit of thirty, the thirty is pushed, but the object's address goes into E C X. And hit ends with ret four: the function removes its own argument. That is this call.
29. (414.5–431.5) Now the game again. Push, push, move E C X, E S I, call. Arguments on the stack, the object in E C X. This call, in the real game. E C X loaded right before a call usually means: an object.
30. (431.5–449.1) And the top of the function. It pushes E B X, E S I and E D I to save them, and pops them back before it returns. In between: move E S I, E C X. That is why E S I was the weapon all along.
31. (449.1–466.0) One last thing. Build the same program as sixty-four bit, and the rules change. Register names start with R, and hold eight bytes. And the first four arguments skip the stack: R C X, R D X, R eight, R nine.
32. (466.0–482.9) So, two worlds. Thirty-two bit, like AssaultCube: arguments on the stack, the object in E C X. Sixty-four bit Windows: arguments in registers, and the object is simply the first one. Always check which world you are in.
33. (482.9–504.4) Let's recap. One line: instruction, destination, source. Brackets mean memory, so register plus offset is a field of an object. Compare plus jump is an if. The stack holds return addresses, and thirty-two bit arguments. Today, we changed nothing. We only read.
