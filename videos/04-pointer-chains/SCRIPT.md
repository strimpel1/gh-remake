# Narration: Follow the Pointers

Voiced with Azure Speech (en-US-AvaMultilingualNeural, rate -4%). Generated by build.py.

1. (0.0–7.6) Your player moves to a new address on every run. Yet the game always finds it. How?
2. (7.6–15.7) It keeps a note in a fixed place: a pointer. A pointer is just a number, and that number is an address.
3. (15.7–24.2) Read the note, and you are standing at the start of the player. Health sits a fixed distance in: offset E C.
4. (24.2–31.0) So the recipe is: read the pointer, then add the offset. In that order.
5. (31.0–38.7) Add first and read second, and you land somewhere else entirely. That is the classic mistake.
6. (38.7–47.8) Real games chain several. Player points to weapon, weapon points to ammo. Read, add, repeat.
7. (47.8–55.0) If a link holds zero, stop. There is no player yet, and reading address zero crashes.
8. (55.0–62.9) A pointer chain is the path the game itself walks. Walk it the same way.
