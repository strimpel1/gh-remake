Game Hacking from Scratch, Episode 1. Your health bar says 100. The game's memory says 64 00 00 00. This episode teaches you to read that line: bits, bytes, hex, data types, little endian and floats, shown on a real open-source game running offline.

📚 IN THIS EPISODE
✅ Bits, bytes and why one byte stops at 255
✅ Hexadecimal: one byte, two digits (100 = 0x64)
✅ How to read a memory viewer: address, bytes, text
✅ char, short, int, long long: the type decides the size
✅ Little endian: why 1000 is stored as E8 03 00 00
✅ Floats, and why the same bytes can be two different numbers
✅ Why every memory scanner asks you for a value type
