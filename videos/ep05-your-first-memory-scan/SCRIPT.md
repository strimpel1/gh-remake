2. (15.6–25.9) Two thousand answers is not an answer. So we will cut that list down to a single address, change the number inside it, and watch the game obey.
3. (25.9–32.8) This is Game Hacking from Scratch. Episode five: your first memory scan.
4. (32.8–47.4) Until now, I showed you values at addresses I already knew. Today you find them yourself. AssaultCube: open source, single player, offline. And Cheat Engine, a free memory scanner.
5. (47.4–61.3) Step one: tell Cheat Engine which program to look at. Click the little computer icon, pick the game's process from the list, and press Open. The process name appears at the top. We are attached.
6. (61.3–78.9) The window has three parts. On the right, the question: a value, a scan type, and a value type. On the left, the answers: every address that matched. At the bottom, the address list: the ones you decide to keep.
7. (78.9–91.3) The value type stays on four bytes. Episode one explained why: a whole number like ammo is almost always stored that way. And the scan type stays on exact value.
8. (91.3–110.3) I type twenty, and press First Scan. Cheat Engine reads all the memory this game can write to, and keeps every address that holds twenty right now. Two thousand, two hundred and fifty-three of them. Twenty is an ordinary number: a menu row, a color, a timer.
9. (110.3–124.3) So I change the value in the game. I fire a few rounds: twenty becomes fourteen. The real ammo address now holds fourteen. Almost all of the others still hold twenty.
10. (124.3–140.2) Now the key move. I type fourteen, and press Next Scan. Next Scan only looks at the addresses already in the list, and keeps the ones that hold fourteen now. From two thousand, two hundred and fifty-three, down to two.
11. (140.2–152.1) That is the whole trick of memory scanning. Scan. Change the value in the game. Scan again. Every round throws out the addresses that did not follow the game.
12. (152.1–164.9) One more round. I fire again: ten left. Next Scan for ten. Still two addresses. Both have followed the counter twice, so this list will not get any shorter.
13. (164.9–176.7) One warning. After the first scan, that button is called New Scan. Press it by mistake, and the whole list is gone. Filtering is always Next Scan.
14. (176.7–189.9) Two addresses left. I double click each one, and it drops into the address list at the bottom. Remember the first one: zero zero eight one, nine three seven zero.
15. (189.9–207.8) Which one is the real magazine? Write to each of them, and see which one the game follows. First, the second address: I type ninety-nine. Cheat Engine shows ninety-nine. The game still shows ten. So this is not the number the game shows.
16. (207.8–218.0) Now the first address. Ninety-nine again. And this time, the counter in the game jumps to ninety-nine. This is the real one.
17. (218.0–231.7) And it is not just a picture. I fire, and the game counts down from my number: ninety-seven, ninety-five. And the second address? It counted down too: the game still writes to it.
18. (231.7–250.3) One more thing the address list can do. Tick the box in the Active column, and keep firing. The counter flickers, but it returns to ninety-five. Cheat Engine has frozen the value: it writes ninety-five back, again and again, several times a second.
19. (250.3–269.7) But a freeze does not stop the game's code. The game still subtracts. Cheat Engine only puts the old number back afterwards. The second address shows it: the game kept subtracting there, down to eighty-seven. The real fix is to change the code. That is episode seven.
20. (269.7–289.9) All of that worked because I knew the number. But what about a health bar, with no number at all? AssaultCube prints its health, so for this part I use a tiny practice program I wrote: Scan Me. Gold is a number. Health is only a bar, with nothing to type into the value box.
21. (289.9–308.0) This is what the scan type list is for. You do not search for a value. You search for a behavior. Increased. Decreased. Changed. Unchanged. And when you only know a limit: Bigger than, Smaller than, or Value between.
22. (308.0–327.1) So, a new scan. Value type: float, because a bar is often stored as a fraction. Scan type: unknown initial value. First Scan. Cheat Engine simply remembers everything. Fifty-nine thousand, three hundred and ninety-two candidates.
23. (327.1–339.8) I press H, and take a hit. The bar gets shorter. So I pick Decreased value, and press Next Scan. Everything that did not go down is thrown out. Seven left.
24. (339.8–358.2) Now the step most beginners skip. I do nothing. So: Unchanged value, Next Scan. In a busy game, this round removes the most: timers, animations, anything that changes by itself. Here, all seven survive.
25. (358.2–373.1) I press R, to rest. The bar grows. Increased value, Next Scan. One address left. And look at its value: ninety-two point five. That is the number the bar was hiding.
26. (373.1–384.1) Same test as before. I add it to the list, write fifty, and the bar drops to exactly half. Found, without ever seeing a number.
27. (384.1–401.9) Two rules. After every change, run one round of Unchanged. And do not assume a direction: some games count the damage you took, so a hit makes the value go up. If Decreased empties the list, start over with Changed value.
28. (401.9–418.2) Now the other way a scan fails. The program shows energy: eighty-seven. I scan for eighty-seven as four bytes, use some energy, and scan for eighty-four. Found: zero. The list is empty.
29. (418.2–434.6) The value is there. I asked with the wrong type. This program keeps energy as a float, about eighty-four point zero four, and prints only the whole part. As four bytes, those same bytes are a completely different number.
30. (434.6–454.3) So: value type float. And because a float is rarely a round number, the scan type is Value between: eighty-four and eighty-five. One result. I use some energy again, scan between eighty and eighty-one, and here it is in the address list: about eighty point seven four.
31. (454.3–471.5) So when a scan finds nothing, change the type. Four bytes first, then float, then the rest. Money and ammo are usually four bytes. Positions and timers, usually floats. A yes or no flag, often a single byte.
32. (471.5–491.7) Now the bad news. I restart the game, and attach Cheat Engine again. The game says twenty. My saved address shows ninety-five, only because the freeze left it there. And the magazine now lives somewhere else: zero zero eight four, six two eight eight.
33. (491.7–508.5) Let's recap. First Scan. Change the value in the game, Next Scan, and repeat. Test what is left by writing to it. No number? Start from unknown, and filter by behavior. Nothing found? Change the type.
34. (508.5–524.8) Your practice. Compile scan me dot C P P from the description. Find the gold: one of the two addresses is a display copy that snaps straight back. Then find the health behind the bar, and set it to exactly half.
