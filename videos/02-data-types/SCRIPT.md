1. (0.0–9.6) You search the game's memory for your health, one hundred. Zero results. The number is right there on screen. So where is it?
2. (9.6–16.4) It is here, in these four bytes. They just don't say one hundred the way you expected.
3. (16.4–24.1) Read them as a whole number and you get one billion, one hundred twenty million. Nonsense for a health bar.
4. (24.1–32.1) Read the same four bytes as a float, a number with a decimal point, and they say exactly one hundred.
5. (32.1–43.8) A whole number one hundred looks completely different: sixty-four, zero, zero, zero. Same value on screen, different bytes in memory.
6. (43.8–55.1) And the bytes run backwards. One thousand is hex three E eight, but memory stores the small end first: E eight, zero three.
7. (55.1–64.0) So when a search finds nothing, change the type. Whole numbers for things you count. Floats for things that move.
8. (64.0–71.6) Memory holds only bytes. The type is how you choose to read them.
