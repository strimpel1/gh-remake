# שיעור 2.4 — Cheat Tables, מקשי קיצור וארגון העבודה

**מודול:** סריקת זיכרון עם Cheat Engine · **יחידות מקור:** How to Create Hotkeys & Cheat Tables (GH106), How To Find Coordinates (GHS107), How to Find Velocity Address (GHS108)

## הרעיון בקצרה

מצאתם pointer לחיים, לתחמושת ולמיקום. בלי לשמור אותם תצטרכו למצוא הכול מחדש בפעם הבאה. **Cheat Table** הוא קובץ ששומר את רשימת הכתובות, ה-pointers, התיאורים ומקשי הקיצור שלכם. זה נשמע כמו עניין של סדר בלבד, אבל טבלה מסודרת היא גם מפת המבנים של המשחק, והיא מה שהופך בהמשך לקוד של trainer.

## לשמור ולטעון

- **Ctrl+S** שומר את הרשימה לקובץ עם הסיומת `.CT`.
- CE מציע לטעון טבלה באופן אוטומטי כשמתחברים לתהליך בשם שתואם לשם הקובץ.
- קובץ `.CT` הוא XML רגיל. אפשר לפתוח אותו בעורך טקסט, וכדאי לעשות את זה פעם אחת כדי לראות שאין שם קסם.

טבלה ששומרת **כתובות ישירות** חסרת ערך אחרי הפעלה מחדש. רק רשומות מסוג pointer, שמתחילות ב-`"game.exe"+offset`, שורדות. לפני ששומרים, מוודאים שכל רשומה היא pointer.

## לארגן את הרשימה

| פעולה | איך |
|-------|-----|
| לתת שם | לחיצה כפולה על העמודה Description |
| לשנות טיפוס | לחיצה כפולה על העמודה Type |
| לקבץ | בוחרים כמה רשומות, לחיצה ימנית, **Create Header**. אפשר לגרור רשומות לתוך כותרת |
| להציג ב-hex | לחיצה ימנית, **Show as hexadecimal** |
| לשכפל עם offset אחר | Ctrl+C ו-Ctrl+V. בחלון ההדבקה אפשר להזיז את כל הכתובות במרחק קבוע |

הטיפ האחרון חוסך הרבה זמן: מצאתם pointer לחיים ב-offset `0xEC`, ואתם יודעים שהשריון ב-`0xF0`? משכפלים את הרשומה ומשנים רק את ה-offset האחרון. השרשרת עד בסיס המבנה זהה לכל השדות של אותו אובייקט.

## Hotkeys

לחיצה ימנית על רשומה ואז **Set/Change hotkeys** (או Ctrl+H) פותחת את חלון מקשי הקיצור. לכל מקש בוחרים פעולה:

| פעולה | מה היא עושה |
|-------|-------------|
| **Toggle freeze** | מדליק ומכבה הקפאה |
| **Set value to** | כותב ערך קבוע, למשל 100 לחיים |
| **Increase / Decrease value with** | מוסיף או מחסיר כמות |
| **Freeze**, **Unfreeze** | הקפאה או שחרור, בלי מיתוג |

בוחרים מקשים שהמשחק לא משתמש בהם. מקשי המספרים במקלדת הנומרית הם הבחירה המקובלת.

## דוגמה: למצוא קואורדינטות ולבנות טלפורט

מיקום הדמות הוא שלושה floats צמודים, ולכן הוא תרגיל מצוין לסריקת ערך לא ידוע:

1. Value Type: Float. Scan Type: Unknown initial value. First Scan.
2. עולים למקום גבוה יותר (מדרגות, קפיצה לגג). **Increased value**.
3. יורדים. **Decreased value**.
4. עומדים במקום. **Unchanged value**.
5. חוזרים על הצעדים עד שנשארות מעט תוצאות.

מתחילים דווקא בציר הגובה, כי קל לשלוט בו: למעלה הוא תמיד "גדל" או תמיד "קטן". בצירים האופקיים הכיוון תלוי בכיוון המפה, וקל להתבלבל.

כשמוצאים את ציר הגובה, שני הצירים האחרים נמצאים 4 בתים לפניו ואחריו. שימו לב שהסדר משתנה בין מנועים: יש מנועים שבהם הגובה הוא Y ויש שבהם הוא Z. פותחים את הכתובת ב-Memory View (Ctrl+B), לחיצה ימנית, **Display Type** ואז **Float**, ורואים את שלושת הערכים זה לצד זה.

עכשיו הטלפורט:

1. מוסיפים את שלוש הקואורדינטות לטבלה כ-pointers, תחת כותרת אחת.
2. עומדים במקום שרוצים לחזור אליו ורושמים את שלושת הערכים.
3. מגדירים לכל רשומה hotkey מסוג **Set value to** עם הערך שרשמתם, ונותנים לשלושתן את אותו מקש.

לחיצה אחת, והדמות קופצת לשם. אם היא נופלת דרך הרצפה, הוסיפו מעט לציר הגובה.

## Speedhack

תיבת הסימון **Enable Speedhack** בחלון הראשי משנה את קצב הזמן שהתהליך רואה: CE מיירט את פונקציות השעון של Windows ומחזיר להן זמן מואץ או מואט. ערך 2.0 מריץ את המשחק פי שניים, ו-0.5 בחצי מהירות.

זה כלי עבודה שימושי, לא רק צעצוע: האטה ל-0.2 מאפשרת לבצע סריקות באמצע קרב בלי למות, והאצה מקצרת המתנות. זה עובד רק על משחקים שהזמן שלהם מחושב אצלכם במחשב.

## מילון מונחים

| מונח | משמעות |
|------|--------|
| **Cheat Table** | קובץ `.CT` ששומר כתובות, pointers, סקריפטים ומקשי קיצור |
| **Header** | רשומת כותרת שמקבצת רשומות אחרות |
| **Hotkey** | מקש שמבצע פעולה על רשומה |
| **Memory View** | חלון שמציג זיכרון גולמי וקוד, נפתח ב-Ctrl+B |
| **Speedhack** | שינוי קצב הזמן שהתהליך רואה |

## בדיקה עצמית

1. שמרתם טבלה, הפעלתם את המשחק מחדש, וכל הערכים מציגים `??`. מה שכחתם?
2. יש לכם pointer לחיים ב-offset `0xEC`. איך מוסיפים את השריון שב-`0xF0` בלי למצוא pointer חדש?
3. למה מתחילים חיפוש קואורדינטות בציר הגובה?
4. מצאתם את ציר הגובה. איפה שני הצירים האחרים?
5. בשביל מה שימושי Speedhack בזמן עבודה?

תשובות: (1) הרשומות הן כתובות ישירות ולא pointers. (2) משכפלים את הרשומה ומשנים את ה-offset האחרון. (3) קל לשלוט בכיוון: למעלה ולמטה ברורים, בלי תלות בכיוון המפה. (4) 4 בתים לפניו ואחריו, כשלושה floats צמודים. (5) האטה מאפשרת לסרוק באמצע פעולה, והאצה מקצרת המתנות.
